# 阿卢工作台 2.0 设计说明

## 目标

将未实际使用的“六部门”个人工作台重构为一款手机优先、个人可持续使用的考研生活工作台。

它帮助用户每天看清个人生活的优先事项，并将每日行动自动汇总为周、月、季、年的可见进度。它不管理工作任务，不重复现有记账工具，不以大量打卡制造压力。

## 成功标准

- 用户打开首页 10 秒内能知道：今天最重要的事、本周学习与运动进度、饮水与睡眠状态。
- 一次日常记录不超过 10 秒；周日复盘不超过 3 分钟。
- 完成一个周任务后，所属月度、季度、年度目标的进度自动更新。
- 安卓可添加到桌面，电脑与手机使用同一份云端数据。
- 不依赖 ChatGPT 会员、ChatGPT 登录或 VPN；不启用任何自动扣费能力。
- 用户可随时导出完整数据。

## 范围

### 保留的能力

- PWA：可安装、响应式、基本离线可打开。
- 项目现有的静态网页发布基础。

### 不迁移的旧功能

- 六部门叙事、怪兽大学角色导航。
- 工作任务、任务回收站与复杂任务库。
- 阅读管理、书籍登记、自媒体灵感和内容解析。
- 详细饮食、体脂、BMI、训练课程和安卓原生壳。
- 旧版本地数据；新版从当前计划周期开始。

### 新版核心功能

1. 总览
2. 计划
3. 记录
4. 复盘
5. 我的

## 使用者与登录

仅供用户本人使用。

- 使用独立邮箱验证码登录，不依赖 OpenAI、ChatGPT 或微信。
- 后端采用腾讯云 CloudBase 免费环境的认证、数据库和静态托管能力。
- 不购买域名，不启用按量付费或付费资源包。
- 以平台默认访问地址作为初始入口；用户需要在免费环境到期前手动续期。
- 数据按登录用户隔离；客户端不能读取其他用户的数据。

## 信息架构

### 1. 总览（默认首页）

展示今天与本周最需要看的内容，最多一屏半：

- 欢迎语与轻量史迪仔插图。
- 今日最重要的 1–3 件个人任务。
- 晨间学习：完成 / 未完成。
- 本周运动：`已完成次数 / 3`，每次至少 20 分钟；Keep、游泳、骑行均可记录。
- 饮水：7 个可点按水滴，1 滴等于 250ml，总目标 1750ml；运动日提示额外 1 杯。
- 昨晚睡眠摘要：时长与主观感受。
- 四条主线的简洁总进度。

总览不展示工作任务、详细账目或必须完成的三餐打卡。

### 2. 计划

展示并编辑目标树：

`年度目标 → 季度目标 → 月度目标 → 周度行动 → 当日任务`

初始年度主线：

1. 考研：2027 年 12 月完成初试。
2. 英语：服务考研并逐步达到日常交流能力。
3. 运动健康：每周 3 次运动，逐步恢复体能。
4. 财务安全：建立 1–2 万元应急金。

用户可新增、编辑、暂停或归档目标和行动。每个目标的进度由其可完成子项自动计算；没有子项时显示手动进度，不伪造百分比。

### 3. 记录

记录不是任务清单，均为快速、可选输入：

- 睡眠：入睡时间、起床时间、主观感受（睡得不错 / 一般 / 很累）。
- 饮食：早餐、午餐、晚餐是否正常吃；每餐可附一段可选备注。
- 饮水：250ml 一杯的快捷加减与当天总量。
- 运动：来源（Keep / 游泳 / 骑行 / 其他）、分钟数、可选备注。
- 体重：每周或每两周记录一次，不作为每日任务。

### 4. 复盘

每周周一至周日计算。周日打开时显示自动汇总：学习、运动、饮水、睡眠和任务完成情况。

只需回答三个问题：

1. 这周最满意的一件事？
2. 哪件事没完成，原因是什么？
3. 下周最重要的 1–3 件事？

### 5. 我的

- 年度目标与习惯设置。
- 饮水杯量和每日目标设置。
- 数据导出、导入和备份提示。
- 登录状态与退出登录。
- 免费环境与备份提示说明。

## 习惯与计划规则

- 唯一默认每日习惯是“早晨学习”。
- 运动是每周目标而非每日失败判定：每周 3 次、每次至少 20 分钟。
- 三餐、睡眠和饮水属于记录入口，不作为每日待办。
- 周日复盘完成后，用户选择或填写下一周的学习与个人任务。
- 每日任务最多 3 个；超出时系统要求用户改为本周任务，避免首页再次变成任务池。

## 数据模型

所有记录附带 `ownerId`，并由服务端/数据库规则验证归属。

| 数据 | 关键字段 | 用途 |
|---|---|---|
| goals | id、parentId、title、period、startDate、endDate、status、manualProgress | 年/季/月/周层级与汇总 |
| tasks | id、goalId、title、date、status、kind、completedAt | 今日及周度行动 |
| habits | id、title、enabled、schedule | 固定晨间学习 |
| dailyLogs | date、sleep、meals、waterCups、exercise、weight | 每日健康记录 |
| weeklyReviews | weekStart、wins、blocker、nextPriorities | 周复盘与计划 |
| profiles | ownerId、displayName、waterCupMl、waterTargetMl | 个人设置 |

进度计算规则：

- 任务完成即记为已完成子项。
- 周、月、季、年目标递归汇总已完成子项比例。
- 只统计状态为进行中的子项；暂停与归档项不拉低进度。
- 对于“每周运动 3 次”这类指标，按当周完成次数计算，不回填历史周。

## 技术设计

### 前端

- 重写为模块化原生 ES Modules：页面、状态、数据访问、进度计算和样式分离。
- 使用轻量、手机优先的单页 PWA；不引入原生安卓项目。
- Service Worker 缓存界面资源。离线时允许查看已同步数据和暂存记录；恢复网络后提示用户同步。

### 云端

- 腾讯云 CloudBase 免费环境：静态网站托管、邮箱验证码认证、数据库。
- 前端只通过 CloudBase 官方 SDK 访问授权后的本人数据。
- 数据库规则按 `ownerId` 限制读写，禁止匿名跨用户读取。
- 不配置 AI、内容抓取、付费模型或后台常驻服务。

### 备份与免费边界

- 不开启按量付费。
- 保留完整 JSON 导出和导入。
- 每周复盘页提醒导出备份；首次上线前展示免费环境需手动续期的提示。
- 若云端免费政策、额度或网络条件变化，用户仍可导出数据并回退至本地使用或迁移。

## 视觉设计

- 风格：浅色、干净、蓝白海岛风。
- 色彩：云白为背景，浅海蓝为主要色，海水绿为完成色，少量珊瑚粉作为强调。
- 史迪仔：只用于欢迎语、空状态、周复盘鼓励和极少量图标，不能占据主界面或替代功能标识。
- 字体与控件优先可读性，卡片留白充足，避免旧版的角色化部门、过多图标和装饰。
- 手机端底部导航为“总览 / 计划 / 记录 / 复盘 / 我的”；桌面端使用简洁左侧导航。

## 验收标准

1. 用户可使用邮箱验证码在手机和电脑登录同一账号，并看到同一数据。
2. 在手机上添加每日任务、勾选完成后，目标树各层进度正确变化。
3. 记录一次 Keep 30 分钟后，本周运动从 `0/3` 更新为 `1/3`。
4. 点按 7 次水滴时显示 1750ml；运动日显示额外补水提醒。
5. 睡眠、三餐和体重均不会被强制作为待办完成。
6. 周日可完成三问复盘，并设置下周 1–3 件重点。
7. 在安卓浏览器可添加到桌面并正常打开；电脑与手机布局均可用。
8. 用户可导出并重新导入完整数据。
9. 项目不包含旧六部门导航、怪兽大学角色、工作任务、内容抓取或 AI 解析入口。

## 范围外

- 微信小程序、原生安卓 App、应用商店发布。
- 工作任务管理、详细账本、自动同步现有记账工具。
- 每餐热量、营养成分、医学建议或自动饮食判断。
- Keep 数据自动读取；用户仅在工作台手动记录完成的运动。
- 多人协作、社交功能、公开分享。
