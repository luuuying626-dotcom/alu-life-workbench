# 阿卢生活工作台：目标、行动与记录重构

## 目的

把工作台从“勾选式展示页”重构为手机上可持续使用的个人系统：今天做什么、长期目标做到哪里、实际生活发生了什么、这一周该如何复盘，都有不同且清晰的口径。

## 约束与成功标准

- 保持 GitHub Pages 静态部署、免费 HTTPS 与本机浏览器存储；不接入付费云服务。
- 保留已有本地数据；旧计划不能因迁移而显示年度 100%。
- 手机优先，适配小米 13 Ultra 的 Chrome/添加到桌面场景。
- 不把工作任务放入本产品。
- 所有数字统计必须明确单位与时间范围。
- 用户能在手机上编辑、删除当日任务；创建年度/季度/月度/周度计划；记录饮食、饮水、运动与睡眠；从周复盘看真实记录。

## 核心概念与数据规则

### 目标（Goal）

目标是长期结果，例如“应急金 20,000 元”。字段为：名称、周期、类型（数值型/阶段型）、单位、目标值、当前值、状态。

- 数值型进度 = `当前值 / 目标值`，限制在 0–100%。
- 阶段型使用手动百分比，默认 0%；不能通过勾选一个子行动自动 100%。
- 月度“存 500 元”可以将财务目标当前值增加 500；该月计划本身完成，但年度目标只按金额比例变化。

### 计划（Plan）

计划是一个周期内的安排，字段为：层级、周期、名称、说明、关联目标、状态。层级只有年度、季度、月度、周度。

- 年度：年份选择器；季度：年份 + Q1–Q4；月度：年份 + 月份；周度：选择任一天后系统确定周一至周日。
- 父级选择器只展示合法上级：季度属于年度、月度属于季度、周度属于月度。
- 计划完成只表示该计划完成。计划树的完成率是下级计划状态的汇总，且与目标指标分开显示。

### 当日行动（Daily task）

当日行动是可勾选的事，字段为：日期、标题、完成状态、可选关联计划。它不直接改变长期目标数值。支持新增、编辑、删除、完成。

### 记录（Daily log）

每日记录以日期为键，稳定保存：三餐文字、饮水杯数、运动项目/分钟、入睡与起床时间、主观感受。所有写入须先创建并挂载到 `state.logs[date]`，再保存到 localStorage。

## 页面设计

### 今天（首页）

- 顶部：公历日期、星期、本周范围与可编辑的鼓励语。
- 今日最重要的事：完整新增、编辑、删除、完成操作；最多三条未完成行动。
- 今日状态：仅显示当天学习/行动、饮水、睡眠与运动记录；不混入本周运动。
- 年度方向：四个简洁目标入口卡，显示目标名称和指标进度，点击进入计划页；不展示计划树。

### 计划

- 顶部“目标”：年度主目标卡，设置或修改单位、目标值、当前值、阶段百分比；展示独立的目标指标进度。
- 中部“当前周期”：按年度、季度、月度、周度切换，周期由选择器设定，非手动文字输入。
- 下部“计划树”：可展开详情，编辑名称、说明、关联目标、完成状态；树中显示计划完成率与目标指标进度的区别。
- 新建流程：先选择层级与周期，再从合法上级与目标中选择归属；可添加行动清单，不要求书写长段文字。
- 初始模板：考研/英语、健康、财务三条主线建立从 2026 Q4 到 2027 年的可编辑季度骨架；不预设用户未确认的具体每日任务。

### 记录

- 今天：早餐/午餐/晚餐为可选文字输入；饮水增减；运动可多条记录；睡眠时间和感受。
- 记录合集：按日期展开显示饮食、饮水、运动、睡眠及当日行动，作为复盘证据。

### 复盘

- 本周范围固定显示周一至周日。
- 统计：计划行动完成数/总数、学习或行动记录天数、运动次数与总分钟、已记录睡眠天数与平均时长、已填写饮食餐数。
- 不展示“正常吃饭”之类含义不清的计数。
- 三个文字复盘问题保留，并在下周优先事项中允许生成行动。

### 我的

- 编辑首页鼓励语或开启默认轮换文案。
- 导出/导入 JSON 备份；清晰说明数据保存在本机浏览器，清缓存或换设备前要备份。

## 视觉设计

采用用户确认的“晨雾海岛”方向：白雾玻璃、冰蓝到靛紫的渐变、柔焦海岛背景、低透明度史迪仔作为首页头图主体。首页顶部为日期和鼓励语的半透明大卡；今日计划为第二张玻璃卡；饮水与睡眠使用两个进度环小卡；底部固定五个圆形/胶囊式入口。页面实际文本必须清楚可读，角色只做背景和留白中的情绪元素，不能遮挡任务、数值或表单。目标进度使用数值、单位和进度环；不使用复杂花纹或工作化表格。

## 数据迁移与错误防护

- 旧 `goals` 迁移为阶段型年度目标，当前值为 0，不继承旧计划树的 100% 状态。
- 已有任务和日志保留；日志规范化后保证 `meals`、`exercise`、`waterCups` 字段存在。
- 保存计划、目标、任务、记录或复盘后立即刷新界面，并可在重开页面后恢复。
- 计划周期与父级不合法时禁止保存并提示用户选择正确层级。

## 验收

1. 新建“11 月存 500 元”并把它完成后，年度“20,000 元应急金”只显示 2.5%。
2. 用户可编辑、删除任一今日行动，刷新后状态仍在。
3. 填写睡眠、三餐、饮水和运动后，刷新仍在记录合集里。
4. 周复盘所有统计可追溯到记录合集或当日行动。
5. GitHub Pages 网址和添加到桌面的 Android 应用均能正常加载。
