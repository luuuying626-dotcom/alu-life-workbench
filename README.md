# 阿卢工作台

一个只供个人使用的本地测试版工作台，网页端和手机端都可以打开；手机端可以安装为 PWA，断网时仍可查看和编辑本地数据。

## 当前信息架构

- 办公厅｜日程统筹：今日任务、任务库、本周节奏
- 财政部｜金钱管理：保留入口，后续开放
- 教育部｜学业进度：英语学习、阅读进度、学习项目
- 卫健委｜身体健康：身体档案、运动管理、饮食饮水
- 发改委｜长期发展：长期目标、自媒体灵感雷达
- 文旅部｜休息娱乐：保留入口，后续开放

办公厅是默认首页，负责把其他部门的任务汇总成今天的清单。电脑端使用左侧部门导航，手机端使用底部导航。六个部门使用《怪兽大学》角色图标，子模块使用简洁字符图标。

## 已实现

- 今日任务：挑选、打勾、编辑、移出今日、新增、优先级、重复周期、可选截止日期
- 任务库：任务移入回收站，不直接永久删除
- 教育部：英语任务、EPUB / PDF / TXT 书籍登记、阅读进度、阅读笔记
- 卫健委：身高、体重、体脂、BMI，运动月度目标示意，饮水和三餐记录
- 发改委：年度目标 / 具体项目的目标卡片，自媒体链接、正文和截图入口
- 后端解析：公开网页抓取、规则回退、可选兼容 Chat Completions 的视觉 / 文本模型
- PWA：manifest、Service Worker、手机响应式布局
- 本地数据：浏览器 localStorage，设置页提供 JSON 导出 / 导入

当前不做：账号登录、云端同步、多人协作、自动爬取抖音 / 小红书、跨境电商功能、财政部和文旅部详细模块。

## 启动本地测试版

在 `运动/阿卢工作台` 目录运行：

~~~bash
npm start
~~~

然后访问：

~~~text
http://localhost:4173
~~~

如果 4173 被占用，可以换端口：

~~~bash
PORT=4317 npm start
~~~

手机和电脑连接同一个 Wi-Fi 后，可使用电脑局域网 IP 加端口访问，例如：

~~~text
http://192.168.1.8:4317
~~~

手机浏览器选择“添加到主屏幕”即可安装为工作台 App。正式云端部署需要后续准备域名、服务器和数据库。

## 后端解析

- GET /api/health：查看解析服务状态
- POST /api/analyze：分析自媒体内容
- POST /api/analyze-resource：菜谱 / 出行攻略整理接口
- GET/PUT /api/state/:workspaceId：为后续云端状态同步预留

没有配置模型密钥时，服务使用后端规则回退；配置后可使用兼容 Chat Completions 的文本 / 视觉模型：

~~~bash
LLM_API_KEY="你的模型密钥" \
LLM_BASE_URL="https://api.openai.com/v1" \
LLM_MODEL="你的模型名称" \
npm start
~~~

平台页面需要登录、反爬或无法公开访问时，粘贴正文 / 字幕 / 图文文字仍可生成初步拆解；不要把“页面无法访问”当成已经解析成功。
